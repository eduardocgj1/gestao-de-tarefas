Calendar-event pill. Appears above a day column's task list, or inside a monthly-calendar cell.

```jsx
<EventChip name="Sprint Review" dotColor="#3E6FBD" />
<EventChip name="Fechamento do Sprint" span="1/2" />
```

A multi-board event uses the neutral `#EFEDE6` bg + `#3E6FBD` dot instead of a single board's color.
